
# 🧹 Husk — Free Windows Optimization Tool

A lightweight, safe, and completely free Windows optimization utility built using pure Python (no external dependencies).

---

## 🚀 Features

- 🧹 **Quick Cleanup**
  - Remove temporary files
  - Clear recycle bin
  - Clean browser cache

- ⚡ **Startup Manager**
  - Enable / disable startup programs
  - Safe backup & restore support

- 🎨 **Visual Effects Control**
  - Optimize performance by disabling animations

- 🔧 **Services Manager**
  - Control non-critical Windows services safely

- 💻 **System Info**
  - RAM, Disk, CPU snapshot

---

## 🛡️ Safety First

- ✔ No registry edits without known safe keys  
- ✔ Startup changes are **reversible**  
- ✔ Only **safe services** are exposed  
- ✔ No tracking, no ads, no data collection  

> ⚠️ Designed to be safe for everyday users.

---

## 📦 Requirements

- Windows 10 / 11  
- Python 3.9+  
- Run as Administrator for full features
